# Brand

Drop your Design System here so every UI the squad produces is born in the right brand.

- **`design-system.md`** — tokens: colors (hex), typography, spacing, radius, elevation,
  plus 1–2 hard brand rules. This is what `product-designer` reads as canonical.
- **`assets/`** — logos, fonts, reference exports (Figma, PDF brand guide).

Until this is filled, `product-designer` falls back to neutral, accessible defaults.
