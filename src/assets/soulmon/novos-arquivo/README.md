# Novos Soulmon: arquivo / archive (sem consumidor / no consumer)

**EN.** Approved art (owner, 2026-10-15) kept here with **no consumer**: nothing in `src/` imports these files, so Vite does not emit them into `dist` and the byte budget is unchanged (REGISTRO §78). The game today uses one branch per creature and has no combined elements; do not invent a mechanic to use them. Contents: `ramos/<element>/<branch>-<champion|ultimate|mega>.png` (2 missing alignment branches for each of the 17 creatures, 102 files) and `combinados/NNN-<id>.png` (138 combined-element rookies). All 256x256 RGBA, binary alpha, nearest-neighbour from the 1024x1024 originals (kept outside the repo in `E:/soulmon-novos-soulmon`). `manifest.json` has the full table (names, alignment, species, role, realm, seed). When a consumer exists, load through a lazy `import.meta.glob`, never from the entry chunk.

**PT.** Arte aprovada (dono, 15/10/2026) guardada aqui **sem consumidor**: nada em `src/` importa estes arquivos, então o Vite não os emite no `dist` e o orçamento de bytes não muda (REGISTRO §78). O jogo hoje usa um ramo por criatura e não tem elementos combinados; não inventar mecânica para usá-los. Conteúdo: `ramos/<elemento>/<ramo>-<champion|ultimate|mega>.png` (2 ramos de alinhamento faltantes por criatura, 102 arquivos) e `combinados/NNN-<id>.png` (138 rookies de elementos combinados). Todos 256x256 RGBA, alfa binário, vizinho mais próximo a partir dos originais 1024x1024 (ficam fora do repo em `E:/soulmon-novos-soulmon`). `manifest.json` traz a tabela completa (nomes, alinhamento, espécie, papel, reino, semente). Quando houver consumidor, carregar por `import.meta.glob` preguiçoso, nunca do chunk de entrada.
