Movimento — três durações, uma curva

120 ms · tap · feedback de toque
200 ms · enter · card e folha
320 ms · page · troca de página
400 ms · scan · varredura do Visor, uma vez

cubic-bezier(.2,0,0,1) fora do visor. DENTRO do visor: steps() sempre (pixel não desliza em subpixel). prefers-reduced-motion: zera duração e loop — reduz o MOVIMENTO, nunca a pausa (a cerimônia continua esperando o gesto).

Divergências com o código de hoje (achados para o staff-frontend)

  • Pixel FORA do visor em 28 .tsx (.sm-px-*, 82 classes; PixelKit importa ui/btn-*.png) — a tese proíbe; o canvas desenha só vetor fora do vidro.
  • lucide-react em 8 arquivos — o motor único é Icon (Material Symbols Rounded subset + GLYPHS).
  • Rótulo da BottomNav em Silkscreen 12px (.sm-bottom-nav-label) — abaixo do piso de 14px e fora do visor; aqui é Rubik 12 (ver FolhaNav).
  • Nenhum token de espaço no CSS — grid de 4 é literal em todo lugar ([pendente do dono] acima).
  • CLAUDE.md diz nav 36 / ações 42 / chat 30 px; o código mede 32 / 24 / 32 (tokens.md §6.1). O canvas segue a escala viva (32) e registra.
  • Sprites das linhas têm 256² nativos; Viewport width=64 scale=3 = 192px = 0,75× — escala fracionária no elemento que exige inteira. Ver o artboard Visor (usa 0,5× = 128px, inteiro em DPR 2).
