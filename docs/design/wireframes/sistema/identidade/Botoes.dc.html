Divergências com o código de hoje (achados para o staff-frontend)

  • .sm-px-btn-sm/md/lg (PixelKit): botão 9-slice em PNG com Silkscreen fora do visor, em 28 arquivos — sai; entra o botão vetor acima.
  • .sm-btn (barra 3D estilo Duolingo, borda cobre 2px) — sobreposição com a variante primária; um só botão primário por token.
  • Estados de foco hoje dependem do outline padrão do navegador em vários botões — o canvas fixa 2px --sm2-primary-ink com offset 3.

FormKit hoje × canvas (X1 — decisão por linha)

  • Botão: FormKit primary / ghost / quiet → canvas primary / outline / ghost / quiet: o ghost do código (surface + line + ink) vira outline (fronteira muted, F2); quiet mantido; ghost novo = ação em ciano sem borda. Canvas vence nos nomes — e o sm2Button('ghost') com consumidores renomeia para outline.
  • Métrica: FormKit 44 / 10·16 / raio 10 / 14px → canvas sm 44 · md 48 · lg 56 / raio 12 / 16px (sm 14). Canvas vence: raio 10 não existe na escala 4/12/20.
  • Chip: FormKit sólido (primary-fill + on-primary, 44) → canvas tonal (primary-soft + borda primary-ink + check, 44). Canvas vence (M3 filter chip; pista de forma além da cor).
  • Campo: FormKit surface-2 + line 1px + anel 2px por box-shadow, raio 10 → canvas igual, com fronteira muted (F2) e raio 12. Código vence no mecanismo do foco.
  • ModalSheet: scrim rgba(4,18,20,.55), sem borda, SM2_SHADOW_SHEET, fechar 44 com ícone 24 muted. Código vence — o canvas copiou os literais.
